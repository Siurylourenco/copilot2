# copilot2
Este repositório contém o resumo do aprendizado e a implementação de um Copiloto com Fluxo de Conversa Personalizado no Microsoft Copilot Studio. O objetivo é demonstrar a criação e personalização de fluxos de conversa, utilizando tópicos, variáveis, entidades e respostas generativas para criar uma experiência de usuário interativa e dinâmica.
